# MechWright

![MechWright icon](assets/branding/icon-dark-256.png)

**MechWright** is a retro-digital visual engineering workbench for RimWorld mechanoids.

Design native Def XML from the ground up: body anatomy, stats, equipment, projectiles, pawn kinds, graphics, audio, mech gestation, spawning, validation and game-ready export. Target: **RimWorld 1.7 + Core and all released DLC**.

**当前状态：设计方案和工程规范已建立；应用功能尚未实现。**

- [完整产品与工程方案](docs/PLAN.md)
- [AI 代理开发规范](AGENTS.md)
- [图标资源](assets/branding/icon-original.png)

Planned desktop stack: **.NET 10 LTS · Avalonia 12 · C#**. Offline-first; Windows-first; portable core.
